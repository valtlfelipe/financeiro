# Js

## Prefer shadcn-vue components
Prefer the existing shadcn-vue components in resources/js/components/ui for UI controls. When a needed component is missing, add the matching new-york-v4 shadcn-vue component using the installed Reka UI and Tailwind dependencies. Compose domain-specific behavior on top of those components instead of rebuilding controls from raw primitives.
